# История изменений VoxVault

Здесь собирается всё, что вошло в релиз. Раздел **«Не выпущено»** — черновик
следующей версии: при выпуске его заголовок заменяется на номер версии, и по
этим строкам пишутся примечания к GitHub Release.

Правило: одна строка — одно изменение, с точки зрения пользователя
(«что изменилось для меня»), а не с точки зрения кода.

## Не выпущено

### Исправления и улучшения
- Приложение перестало предлагать то, чего нет. У части языков в реестре VOSK
  только один размер (`ar` — лишь большая, `ca` — лишь маленькая), и раньше
  в интерфейсе светилась кнопка «Скачать (small)» для `ar`, в списке размера
  в главном окне стояли оба варианта, а `dictophone list` печатал `small=-` —
  непонятно, это «нет модели» или «сбой вывода». Теперь:
  - вкладка «Модели» показывает **отдельный блок на каждую модель** (малая и
    большая — это разные модели): свой заголовок с именем архива, своя строка
    состояния, свои кнопки «Скачать» и «Удалить». Раньше на весь язык была одна
    пара кнопок, и при двух установленных моделях было непонятно, к какой из них
    они относятся, а удалялась та, чей каталог последним попал в кэш;
  - блока несуществующего размера нет вообще, а в заголовке написано словами
    `large — нет в реестре VOSK`;
  - кнопка «Прогреть модель сейчас» подписана моделью из главного окна
    («Прогреть модель сейчас: ru/large») и гаснет, если этой модели на диске
    нет;
  - в списке языков показан суммарный размер обеих моделей: раньше для `ru` со
    small+large показывалось 3524 МБ — то есть размер только большой;
  - в списке размера в главном окне — только реально существующие для языка
    размеры (плюс «авто»); при переходе на язык без выбранного размера
    остаётся «авто», и это значение пишется в настройки;
  - `dictophone list` печатает «нет в реестре» вместо `-` и добавляет список
    языков с единственным размером.
- Диалог скачивания модели показывает имя архива рядом с размером.

## 0.1.2 — 2026-09-26

### Исправления и улучшения
- Нескачанная модель распознавания больше не выглядит как поломка: при её
  выборе в списках и при нажатии «Запись» приложение спрашивает, скачать ли
  модель, и скачивает прямо из этого диалога. Раньше в этом месте
  показывалась ошибка с инструкцией для командной строки.
- **Большая модель русского языка (ru-0.42) больше не удаляется после
  скачивания.** Проверка распакованной модели требовала файлы графа `Gr.fst` и
  `HCLr.fst`, которых нет в новых моделях (там один `HCLG.fst`): архив на
  1,8 ГБ скачивался, распаковывался и тут же удалялся как «неполный».
  Теперь достаточно акустической модели, конфигов и любого `graph/*.fst`.
- В окне «О программе» появились версия программы и проверка обновлений:
  приложение тихо проверяет релиз на GitHub (не чаще раза в сутки) и, если
  вышла новая версия, пишет об этом в строке состояния и в пункте меню.
  Само обновление не скачивается — приложение открывает страницу релиза в
  браузере.
- На панели задач Windows теперь иконка VoxVault вместо значка Python.
- Появилась команда `dictophone --version` — версию проще приложить к отчёту
  об ошибке.

### Для разработчиков
- Контроль качества кода: `pre-commit` с ruff (lint + формат), mypy и bandit,
  одна команда настройки (`scripts\setup-dev.ps1`) и те же проверки в CI.
  Попутно исправлены дефекты, найденные mypy: сигнал Qt-объекта перекрывал
  виртуальный `QObject.event`, а метод `Storage.list()` — встроенный `list`,
  из-за чего часть аннотаций переставала быть типами.

## 0.1.1 — 2026-09

- Релиз одним файлом: в архив попадает только `VoxVault.exe`, без папки
  `_internal`.
- Починка проверки состава архива: один файл в zip больше не считается
  ошибкой сборки.

## 0.1.0 — 2026-09
